# BidNow: Real Time Auction Experience

## Milestone-1 Overview

This milestone focuses on creating user-friendly UIs for the Registration, Login, and Password Recovery Pages. Form validation for format and length ensures that the submit buttons are only enabled when the input is correct. Upon successful submission, the user is redirected accordingly.

### 1. Landing Page
The landing page features the application name and a "Get Started" button. Clicking this button redirects the user to the registration page.

### 2. Registration Page
This page contains the following input fields:

- Name
- Email
- Password
- Confirm Password

Users can choose to register as either a buyer or seller. If they already have an account, they can click the login link to be redirected to the login page.

### 3. Login Page
This page contains two input fields:

- Email
- Password

A "Forgot Password?" link allows users to recover their password. Additionally, there is a link to the registration page for new users.

Admin credentials are stored within the application and do not require prior registration.

### 4. Forgot Password
The password recovery page has a single email input field. Upon clicking the "Send Reset Link" button, a prompt informs the user that a reset link has been sent to their email.
